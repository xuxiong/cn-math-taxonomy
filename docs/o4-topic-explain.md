## 0. 结论摘要（一屏看完）

知识点页（`explore/#<topicId>` 的详情面板）现在是一张**元数据卡 + 图谱导航**：一句话介绍（全库中位 31 字）、掌握标准（中位 2 条）、课标原文（中位 38 字）、样题 1 道、先修/被依赖列表。没有一句是讲给孩子听的话——第一次接触这个知识点的孩子读完，仍然不知道"这是什么、为什么要学、第一步怎么做"。

本文定的是：在知识点页加一个「让 AI 讲一遍」的入口，**按需生成**（用户点了才调模型）、**全量覆盖 3297 个点**（10 学科 / 1–16 年级）、输出**固定 5 段结构**（每段小标题 + 分点/分步，不是一大段散文）、过**3 道确定性闸门**才上屏、一律打 **AI 生成**标；讲解通过后可以在同一处**跟 AI 老师多轮追问**（真 `messages` 多轮，不是把历史拼成一段文本）。

> **口径修订（2026-11-08，优先级最高，覆盖下文所有冲突表述）**
> 用户裁定：① **不引用具体课标**（避免讲错课标；`cms-2022` 编号与课标原文一律不进 prompt、不进素材、不校验）；② **不做字数/句长/行数这类计数校验**（G6 与 §4.2 的档位表作废）；③ **排版要清晰、不要一大段文字、至少支持 AI 老师「出题 → 回答」的格式**（例子段 = 题面 + 分步解答 + `答案：`，由 prompt 与渲染层保证，不靠闸门计数）。
> ④ **不设数字白名单**（G7 删除）；⑤ **不禁全角符号、早期档「禁符号」也删除**（1–2 年级有 42 个点本身就是「5以内的加法 / 口算加法」这类，禁符号会整批误杀，`toNarrow` 随之归零删除）。
> 因此：G2/G3/G4/G6/G7、生活场景、禁符号、字数行数全部删除；**只剩 G1 结构 / G5 卫生两道**（§5）。

## 2. 目标 / 非目标

**目标**：第一次接触这个知识点的孩子，读完 5 段能说出三件事——这是什么、为什么要学、第一步怎么做；没读懂的地方能**当着 AI 老师的面直接问**，问到自己懂。

**非目标**：
- 不做题库、不做诊断判分、不做难度判定
- **不替孩子做题**：追问要"这题答案"时，按 D22 引导"你自己算，卡在哪一步我帮你看"
- 不生成图（带图内容的"可画性"无法验证，沿用既有红线：默认不生成）
- 不替代课标与教材原文，只做"转成人话"
- 不做跨知识点的长对话（换知识点 = 换会话）
- 不做摘要压缩、不做跨会话续聊（见 §8.3 / §8.4）

## 4. 输出结构 + 语言四档

### 4.1 讲解五段（JSON，键名固定）

```json
{ "what":  "这是什么（1–3 个分点，一点一行）",
  "why":   "为什么要学 / 生活里哪用得上（1–3 个分点）",
  "how":   "怎么做（分步，每步一行，以 1. 2. 3. 开头）",
  "demo":  "看个例子（第一行题面（问句）→ 中间分步解答 → 最后一行「答案：…」）",
  "trap":  "容易错的地方（1–2 个分点）" }
```

段内用 `\n` 分隔分点/步骤，**不要写成一大段文字**。这是排版的主约束，写在 prompt 里，由渲染层落实（§4.3），**不用闸门计数**。

### 4.2 排版（取代原「字数上限四档」，2026-11-08）

原按 `grade` 分档的字数/句长上限**作废**（用户裁定不检查字数、行数）。改由三条结构性约束保证可读性：

| 段 | 排版要求 |
|---|---|
| what / why / trap | 1–3 个分点，一点一行 |
| how | 分步，每步一行，`1.` `2.` `3.` 开头；不许写成「先…然后…最后…」一整句 |
| demo | **AI 老师出题-回答格式**：第 1 行题面（必须是问句）→ 分步解答 → 最后一行 `答案：…` |

闸门只校验 **demo 里有问句、有「答案：」行**（存在性，不计数）；其余靠 prompt 与渲染。

### 4.3 渲染（卡 B 实现）

- 每段一个容器：小标题 + `<ul><li>`（`demo` 用 `<ol>`）
- `demo` 题面一行加粗，`答案：…` 折叠（复用样题「查看答案」的 `<details>`）
- **禁止把 5 段拼成一段文本上屏**

## 5. 闸门（只剩两道；2026-11-08 口径修订后）

> 删掉的：G2 不超纲 / G3 算式一致 / G4 课标忠实 / G6 长度 / **G7 数字白名单** / 早期档「生活场景」/ 早期档「禁符号」/ `toNarrow` 全角归一。
> 理由：G2/G3 是"正确性代理"却挡不住真正的概念错误，且有误杀成本；G4 与「不引用课标」直接冲突；G6 与一切计数判据按用户裁定不做；G7 用户明确不需要；「生活场景」词表穷举不住（实测被「个」字骗过）；**「禁符号」会把 1–2 年级 42 个算式类点（5以内的加法 / 口算加法等）的正常讲解整批误杀**，故一并删除，`toNarrow` 随之零消费者。
> 判据只剩一种：**结构完形**。

## 6. 学科 × 学段语气表（全量带来的主要新增工作）

`explain.js` 的 systemPrompt 是数学专用（"人教版初中数学的一对一辅导老师"）。全量跨 10 学科，语气必须切，否则会拿数学老师的口吻讲古诗和时态。

| 学科 | 语气与落点 | 禁用 |
|---|---|---|
| 数学 | 讲算理，先"为什么"再"怎么做"，例子必须是算式题 | 不许出现未定义符号 |
| 物理 | 讲现象 → 规律 → 公式，例子用生活装置 | 不许编实验数据 |
| 化学 | 讲物质与反应，例子用投放的题目 | 不许编反应式（没投放就不写） |
| 生物 | 讲结构与功能对应 | 不许编物种/数字 |
| 科学（小学） | 只讲现象与观察，不引入术语 | 不用公式 |
| 语文 | 讲字词/句式/文体的规则，例子用真题句 | 不许编诗句原文（原文只能引投放素材） |
| 英语 | 讲用法与语境，例子用真题句 | 不许编语法术语的中文误译 |
| 历史 | 讲事件因果与时间定位 | **不许编年份、人物、地名**（只能引用投放素材里的） |
| 地理 | 讲空间与成因 | 不许编数据 |
| 道法 | 讲概念与情境判断 | 不许编法条编号 |

学段（§4 四档）与学科语气正交：**档位决定长度，学科决定口吻与素材偏好**。追问沿用同一套 system 人设（D16），不另起一段人设。

## 7. 交互与状态机

| 状态 | 触发 | UI |
|---|---|---|
| 未配模型 | 该 origin 无 key | 按钮文案"先把模型配好才能让 AI 讲"，点它跳 `diagnose/settings.html` |
| 未生成 | 详情面板展开 | 引导条 +「让 AI 讲一遍」按钮 |
| 生成中 | 点击后 | 就地进度文案（沿用现有 loading 风格），3–8s 预期；可离开不打断 |
| 通过 | 3 道闸门全过 | 5 段渲染（走卡 H 纯 DOM 渲染层，**禁 `innerHTML`**）+ 底部「AI 生成 · 未经人工审核」+「换个说法重讲」，**并出现对话输入框** |
| 被拒 | 任一闸门不过 | 一行原因 + 重试按钮（限 1 次）；**不出现对话输入框** |
| 网关错误 | HTTP 200 但返回网关业务错误包（如 `{"retCode":9}`，无 `choices`） | 一行「AI 老师那边暂时没接通，过一会儿再试一次」+「再试一次」按钮；**不出现对话输入框** |
| 命中缓存 | 同 topicId + 同素材版本 + 同模型 | 直接渲染讲解（无网络请求）；对话按 D20 恢复 |
| 对话中 | 讲解通过后 | 气泡区（学生右 / 老师左）+ 输入框 + 发送；空输入禁用、>100 字拒绝 |
| 对话到顶 | 满 10 轮 | 输入框禁用 + "这次聊得够多了，清空重来会更好"+「清空对话」 |
| 本轮失败 | 超时 / 空 / 被闸门拒 | 气泡位留一行「没答上来（原因：超时），再说一次」+ 重试；**不写 history** |

**关键约束**：讲解未通过闸门时**不出现**对话输入框——追问的锚点必须是已上屏的那 5 段。

## 8. 多轮追问（用户追加要求，本节是完整口径）

### 8.1 消息序列（真 messages）

```
[0] system      : 角色 + 学科语气 + 语言档 + 只答本知识点 + 不替孩子做题 + 禁用法
[1] user        : 素材块（§3 七项，含介绍/掌握标准/例题，**不含课标**）
[2] assistant   : 讲解 5 段（JSON 转成带小标题的文本）
[3] user        : 学生第 1 问
[4] assistant   : 回答 1
[5] user        : 学生第 2 问
[6] assistant   : 回答 2
...
```

- **[0][1][2] 是锚点，永不出窗口**（D17）——它们定义了"讲的是哪个知识点的哪一版讲解"
- 中间问答按窗口裁剪：保留最近 **6 轮**（12 条），并按总字符 **≤4 000 字**从最早轮起丢；被丢的轮次**不影响 UI 展示**（气泡仍全显示），只影响送模型的上下文
- 每轮回答**不要求 JSON**：模型直接返回纯文本（避免 `response_format: json_object` 在短回复上产生废 JSON 与半截截断）；只有讲解轮用 JSON

### 8.2 为什么不用 `explain.js` 那种"拼历史"

| 维度 | `explain.js` 现状（最近 2 轮拼文本） | 本文（真 messages） |
|---|---|---|
| 角色边界 | 丢（全在一条 user 里） | 保留（assistant/user 分开） |
| 可回溯轮数 | 2 | 窗口 6 轮 + UI 全量 |
| 与讲解的耦合 | 与"三步讲解进度"绑死 | 与 5 段讲解绑定，天然是锚点 |
| 稳定性 | 每轮重拼，易漂 | 一轮一条，稳定 |
| 成本 | 略低 | 略高（几条 message 元数据），可忽略 |

不复用的原因不是"它坏了"——错题场景本就只需最近 2 轮；是知识点对话需要更长、更稳的上下文。

### 8.3 上下文与成本上限

| 项 | 值 |
|---|---|
| 锚点固定开销 | 素材块 ~700 tokens + 5 段讲解 ~600 tokens ≈ 1.3k |
| 每轮增量 | 学生问 ~50 + 回答 ~150 ≈ 200 tokens |
| 满窗口（6 轮）时每轮输入 | ≈ 1.3k + 1.2k ≈ 2.5k tokens |
| 单次会话最坏（10 轮） | ≈ 25k 输入 + 2k 输出 tokens |
| 缓存命中 | 讲解不出网（0 token），对话从 0 开始 |

**不做的事**：不做摘要压缩（10 轮上限已经够小，摘要是又一个不可测环节）；不做跨会话续聊（关页面再进来：讲解在缓存里，对话按 D20 留最近 12 轮，会话轮数计数刷新即重置）。

### 8.4 存储

| 槽 | key | 内容 | 淘汰 |
|---|---|---|---|
| 讲解 | `cnmDiagnose.topicExplain.v1` | `{ topicId, hash, model, segs:{what,why,how,demo,trap}, at }` | 200 条 LRU，单条 ≤6KB |
| 重讲版 | `…v1.alt` | 同上，每点只留 1 条 | 同上 |
| 对话 | `…v1.chat.<topicId>` | `[{q,a,at}]`，≤12 轮 | 最多留 3 个 topic（LRU） |
| 会话轮数 | 内存 | 本会话已用轮数（上限 10） | 刷新即重置（防"刷轮数绕上限"） |

- 素材或模型变更 → 讲解 key 变 → 旧对话**一并失效**（锚点不一致，继续聊会串味）
- 「换个说法重讲」→ 清空该点对话（D12）
- 「清空对话」→ 只删 chat 槽，保留讲解

### 8.5 追问轮的额外护栏

- system 明写：只回答与「<知识点名>」相关的问题；问到别的知识点，回一句"咱们先把这个弄明白"再引导回来（**不是硬拒**，避免挡住正常提问）
- 问到"直接告诉我答案" → 引导"你自己算，卡在哪一步我帮你看"（§2 非目标）
- 学生输入里的指令性文本（"忽略上面的要求"之类）不做特殊过滤，靠 system 护栏 + G2′/G5 兜底；**不因此拒掉整轮**（否则正常提问会被误伤）

## 9. 红线与不可测披露

**红线**
- 不改 `explain.js` / `variants.js` / `llm-variants.js` / `llm-gates.js` 语义
- 不写 `data/*.json`、不动 `sw.js`（`VERSION` 与缓存策略一律不碰）
- 禁 `innerHTML` / `insertAdjacentHTML` / `document.write` / `Function` 求值；白名单标签沿用卡 H
- 不设学科/年级白名单（全量 3297）
- 讲解与**每一条**对话回复都打「AI 生成 · 未经人工审核」
- **不许写死数字**：超时读 `llm-config.js` 的 `timeouts.chat`，`maxTokens` 读 `maxTokens.*`
- 零网络依赖测试：模型调用必须可 mock，单测不发真请求

**不可测披露（如实申报）**
- 孩子"听不听得懂"没有任何机器判据，闸门只保证**结构合法 + 与库内素材一致**
- 多轮质量更不可测：能测的只有"锚点未丢""轮数上限生效""闸门逐轮执行""失败轮不入史"，测不了"越聊越靠谱"
- 非数学 2427 个点（英语 791 / 语文 682 / 物理 269 / 科学 222 / 道法 159 / 历史 134 / 生物 66 / 地理 59 / 化学 45）**没有任何人工复核过**
- 课标库 786 条的 `text_status` 自标"公开转写，未与教育部 PDF 逐页核对"——引用的是这份转写文本
- 1–2 年级语言极简与"讲清进位原理"有张力：可能讲不透，后续只能靠"图标化"另议，本方案不出图

| 卡 | 范围 | 验收要点 |

| 卡 A：纯模块 | `diagnose/topic-explain.js`：素材组装（去课标）+ prompt（学科×学段）+ 5 段解析 + 讲解 3 闸 + **追问轮（messages 组装、窗口裁剪、失败不入史、轮数计数）** + 缓存读写；零 DOM、零网络（模型注入可 mock） | 闸门逐条正负例；窗口裁剪与锚点不裁的边界用例（第 6/7/11 轮）；10 学科 × 4 档 prompt 快照；不给模型真调 |
