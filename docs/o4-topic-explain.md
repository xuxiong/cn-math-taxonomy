# O4-1 设计：知识点页 AI 讲解（全量 3297 点，按需生成）

状态：口径已定稿（2026-11-07，用户逐条裁定）｜本文只产口径与拆卡建议，不实现
关联：O2 = `diagnose/explain.js`（**题目**讲解，答错后三步引导）｜O3 = `diagnose/llm-variants.js`（LLM 变式**出题**）｜本文 O4 = 知识点页的**概念**讲解，与 O2/O3 职责不重叠

## 0. 结论摘要（一屏看完）

知识点页（`explore/#<topicId>` 的详情面板）现在是一张**元数据卡 + 图谱导航**：一句话介绍（全库中位 31 字）、掌握标准（中位 2 条）、课标原文（中位 38 字）、样题 1 道、先修/被依赖列表。没有一句是讲给孩子听的话——第一次接触这个知识点的孩子读完，仍然不知道"这是什么、为什么要学、第一步怎么做"。

本文定的是：在知识点页加一个「让 AI 讲一遍」的入口，**按需生成**（用户点了才调模型）、**全量覆盖 3297 个点**（10 学科 / 1–16 年级）、输出**固定 5 段结构**、过**5 道确定性闸门**才上屏、一律打 **AI 生成**标。

## 1. 现状（实测读数，2026-11-07）

### 1.1 知识点页面现在有什么（`explore/app.js` 详情面板 `:580-650`）

| 区块 | 内容 | 实测 |
|---|---|---|
| 标题行 | 名称 + 学段 pill + id | — |
| 唯一 CTA | 「诊断这个知识点」 | 全页只有这一个行动入口 |
| meta-grid | 年级册次 / 领域 / 类型 / 章节 | 结构化元数据 |
| 一句话介绍 `description` | 例："会口算两位数加一位数或整十数，包括进位。" | 3297 点全覆盖，**中位 31 字**（最短 10 / p90 56 / 最长 144） |
| 掌握标准 `mastery_criteria` | 短句清单 | 中位 2 条（最多 3，无空） |
| 课标条目 | cms id + 对应度 + 课标原文 | 课标库 **786 条**，原文中位 38 字；3295/3297 点有关联 |
| 样题 | 1 道 + 可展开答案 | — |
| 先修 / 被依赖 | 图谱导航 | — |

结论：这是**给系统与人看的元数据**，不是讲给孩子的话。

### 1.2 已有的 AI 能力都不是这件事

- `diagnose/explain.js`：只在**答错一道题之后**出现，`systemPrompt` 写死"人教版初中数学的一对一辅导老师"，输入只有 `知识点名 + 题面 + 参考答案 + 该题解析`——**连 description 和课标都没喂**，且只讲这道题。
- `diagnose/llm-variants.js`（O3）：出题，不是讲解。
- 结论：**「讲清一个知识点」这件事目前是空白，不是"已有但弱"。**

## 2. 目标 / 非目标

**目标**：第一次接触这个知识点的孩子，读完这 5 段，能说出三件事——这是什么、为什么要学、第一步怎么做。

**非目标**：
- 不做题库、不做诊断判分、不做难度判定
- 不做多轮追问（那是 `explain.js` 的 `ask` 能力，另议）
- 不生成图（带图内容的"可画性"无法验证，沿用既有红线：默认不生成）
- 不替代课标与教材原文，只做"转成人话"

---

## 3. 素材投放清单（输入）

| # | 素材 | 来源 | 缺省处理 |
|---|---|---|---|
| 1 | 知识点名 | `topic.name` | 必有 |
| 2 | 学段 / 年级 / 册次 / 章节 | `topic.grade / semester / chapter` | 必有 |
| 3 | 一句话介绍 | `topic.description` | 必有 |
| 4 | 掌握标准 ≤3 条 | `topic.mastery_criteria` | 必有 |
| 5 | 课标原文 | `topic.standards[].id` → `cn-data/cn-curriculum-standards.json` 的 `text` | **无课标 → 跳过 G4 + 上屏注明** |
| 6 | 例题 2–3 道（题面 + 答案 + 解析） | 该 `topicId` 的题库，按 `difficulty` 升序取最易的 2–3 道 | 无解析的题只用题面与答案 |
| 7 | 直接先修知识点名 ≤6 个 | 先修图 | 无先修 → 写"这是起点" |
| 8 | 学科语气档 + 语言档 | 见 §6 / §4 | 必有 |

**红线**：模型只许重述这些素材里的事实。素材里没有的数字、概念、人物、年份，一律不许出现（G2/G3 拦）。

## 4. 输出结构 + 语言四档

### 4.1 五段（JSON，键名固定）

```json
{ "what":  "这是什么",
  "why":   "为什么要学 / 生活里哪用得上",
  "how":   "怎么做（最多 3 步）",
  "demo":  "看个例子（用投放的例题，算式要与题库一致）",
  "trap":  "容易错的地方" }
```

### 4.2 字数上限（按 `grade` 分档，可断言）

| 档 | 年级 | 每句上限 | 各段上限（what/why/how/demo/trap） | 额外规则 |
|---|---|---|---|---|
| 幼儿级 | 1–2 | 12 字 | 40 / 40 / 60 / 70 / 40 | 禁符号公式，只说"怎么做"，必须有一个生活场景 |
| 小学高年级 | 3–6 | 20 字 | 60 / 60 / 90 / 110 / 60 | 允许算式，要讲"为什么" |
| 初中 | 7–9 | — | 80 / 80 / 120 / 150 / 80 | 允许步骤化推导与符号 |
| 高中 | 10+ | — | 100 / 80 / 140 / 160 / 100 | 允许抽象定义，可加一句严谨表述 |

超上限 = G1 不过。

## 5. 五道确定性闸门（这是"没法人工判断"的补偿手段）

| # | 闸门 | 判据（可断言） | 不过时 |
|---|---|---|---|
| G1 | 结构 | 5 键齐全、无空段、每段字数在档内、句数 ≤ 档内上限 | 拒 |
| G2 | 不超纲 | 讲解文本里出现的**知识点名**必须 ∈ {本点} ∪ {直接先修}（白名单由数据算出，不许手写字面表） | 拒 |
| G3 | 引用一致 | 讲解里出现的算式，其操作数必须能在该点题库题面中找到；`demo` 段的答案数字必须等于某道题库题的答案（复用 `llm-eval.js` 的数值比对） | 拒 |
| G4 | 课标忠实 | 若引课标原话，必须带 `cms-2022:*` id 且 ∈ `topic.standards` | 拒（无课标点跳过本闸门） |
| G5 | 文本卫生 | 无 `**` / `#` / 反引号 / LaTeX 反斜杠命令 / 占位符 `…` 残留（走 `textfmt.normalize` + `cleanLatex`，不另写一份实现） | 清洗后仍不过 → 拒 |

**被拒的形态**：显示"这条讲解没通过自动校验（原因：示例算式与题库不一致），换一次试试"，允许重试 1 次；不许把半成品上屏，也不许静默回退成空。

## 6. 学科 × 学段语气表（全量带来的主要新增工作）

`explain.js` 的 systemPrompt 是数学专用（"人教版初中数学的一对一辅导老师"）。全量跨 10 学科，语气必须切，否则会拿数学老师的口吻讲古诗和时态。

| 学科 | 语气与落点 | 禁用 |
|---|---|---|
| 数学 | 讲算理，先"为什么"再"怎么做"，例子必须是算式题 | 不许出现未定义符号 |
| 物理 | 讲现象 → 规律 → 公式，例子用生活装置 | 不许编实验数据 |
| 化学 | 讲物质与反应，例子用投放的题目 | 不许编反应式（没投放就不写） |
| 生物 | 讲结构与功能对应 | 不许编物种/数字 |
| 科学（小学） | 只讲现象与观察，不引入术语 | 不用公式 |
| 语文 | 讲字词/句式/文体的规则，例子用真题句 | 不许编诗句原文（原文只能引投放素材） |
| 英语 | 讲用法与语境，例子用真题句 | 不许编语法术语的中文误译 |
| 历史 | 讲事件因果与时间定位 | **不许编年份、人物、地名**（只能引用投放素材里的） |
| 地理 | 讲空间与成因 | 不许编数据 |
| 道法 | 讲概念与情境判断 | 不许编法条编号 |

学段（§4 四档）与学科语气正交：**档位决定长度，学科决定口吻与素材偏好**。

## 7. 交互与状态机

| 状态 | 触发 | UI |
|---|---|---|
| 未配模型 | 该 origin 无 key | 按钮文案"先把模型配好才能让 AI 讲"，点它跳 `diagnose/settings.html` |
| 未生成 | 详情面板展开 | 一个引导条 +「让 AI 讲一遍」按钮 |
| 生成中 | 点击后 | 就地显示进度文案（沿用现有 loading 文案风格），3–8s 预期；可离开不打断 |
| 通过 | 5 道闸门全过 | 5 段渲染（走卡 H 的纯 DOM 渲染层，`render/segments`，**禁 `innerHTML`**）+ 底部「AI 生成 · 未经人工审核」+「换个说法重讲」 |
| 被拒 | 任一闸门不过 | 一行原因 + 重试按钮（限 1 次） |
| 命中缓存 | 同 topicId + 同素材版本 + 同模型 | 直接渲染，无网络请求 |

## 8. 缓存与失效

- key：`topicId | 素材版本 | 模型名`；素材版本 = 对（`description` + `mastery_criteria` + 课标 text + 投放题目 id 列表）求哈希
- 存 `localStorage['cnmDiagnose.topicExplain.v1']`，单条 ≤6KB，最多保留 200 条（LRU 淘汰）
- 素材或模型任一变 → key 变 → 自然 miss（不做主动清理）
- 「换个说法重讲」= 强制 miss 一次，写进**另一个槽**（`…v1.alt`，只留 1 条/点），避免覆盖首选版本

## 9. 红线与不可测披露

**红线**
- 不改 `explain.js` / `variants.js` / `llm-variants.js` / `llm-gates.js` 语义
- 不写 `data/*.json`、不动 `sw.js`（`VERSION` 与缓存策略一律不碰）
- 禁 `innerHTML` / `insertAdjacentHTML` / `document.write` / `Function` 求值；白名单标签沿用卡 H
- 不设学科/年级白名单（全量 3297）
- 讲解文本一律打「AI 生成 · 未经人工审核」
- 零网络依赖测试：模型调用必须可 mock，单测不发真请求

**不可测披露（如实申报）**
- 孩子"听不听得懂"没有任何机器判据，闸门只保证**结构合法 + 与库内素材一致**
- 非数学 2427 个点（英语 791 / 语文 682 / 物理 269 / 科学 222 / 道法 159 / 历史 134 / 生物 66 / 地理 59 / 化学 45）**没有任何人工复核过**
- 课标库 786 条的 `text_status` 自标"公开转写，未与教育部 PDF 逐页核对"——讲解引用课标原文时，引用的是这份转写文本
- 一年级两档（1–2 年级）语言极简与"讲清进位原理"有张力：可能讲不透，后续只能靠"图标化"另议，本方案不出图
