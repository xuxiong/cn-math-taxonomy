## 2. 新增「AI 老师」一节（`.hero` 之后、三步之前）

```html
<section class="ai-teacher">
  <h2>AI 老师</h2>
  <p>知识点可以让它讲一遍，做题卡住了可以问它。</p>
  <article class="ai-card"> 讲一个知识点 … <a href="explore/#cnm_p031">看一个例子：口算加法</a> </article>
  <article class="ai-card"> 陪你把题做完 … <a href="diagnose/?target=cnm_221&amp;demo=1">看一个例子：配方法</a> </article>
  <p class="ai-note">第一次用 AI 功能会让你填一个模型，只存在这台设备上。</p>
</section>
```

措辞边界（写死在 `tests/test_home_copy.js` 第 4 条里）：

- 只允许「讲解由 AI 生成，未经人工审核」，不许出现「已验证 / 已审核 / 保证」。
- 卡片二只写「再来一道可以换一道同难度的题接着练；出不了会直接告诉你」，不写「AI 给你出题」——实际只有 19 个点由程序构造、1065 个点按参数生成，其余明说支持不了。
- 不写课标编号、不写教材版本名。

样式只新增 `.ai-teacher` / `.ai-card` / `.ai-note` 三个类，写在 `index.html` 的 inline `<style>` 里（不进 `assets/site.css`：那份是 explore 也要下的共用样式，加字节会吃首屏预算余量）。桌面两列、≤800px 单列。
